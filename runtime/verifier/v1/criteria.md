# v1 验收标准：多 Agent Runtime 容器后端纵切片

基线：`dba7246fa397b9556c05a798fa1c77cd21bf8a9d`。

1. 既有插件、PKX、订阅插件包及其支付体系文件零改动；新能力只走独立 runtime 编排面。
2. 真实 canonical MySQL 表保存计划、岗位任务、事件、租约、结果哈希、幂等键与版本；浏览器不是事实源。
3. Owner 可控制本企业全部编排；部门负责人仅本部门；普通成员、跨企业和跨部门均拒绝。
4. 自然语言计划只能由 SCNet `DeepSeek-V4.1-Flash-1017` 真实生成；失败不得模拟。结构化任务用于无模型测试，不冒充自然语言证据。
5. 计划必须经人工确认后派发；命名 runtime 未配置时不得替换供应商，auto 只能显式选择已配置适配器。
6. 多任务可并行 claimed；租约带 fencing token；撤销后迟到结果只能记 `outcome_unknown`，不得进入交付。
7. runtime 返回只进入 `awaiting_review`；创建人不得验收自己的任务；接受后才 `accepted`；本面不触发工资。
8. 幂等重放不得重复调用规划或创建任务；同键不同请求必须冲突。
9. 类型检查、单元测试、真实隔离 MySQL 集成测试全部通过；所有执行记录写入 `verifier/runs/`。
