纪律面

三层不混：老板驾驶舱（业务拍板）/门户管理台（运营动作）/组织运行时管理台（运行时异常）。

异常优先：默认只显示异常与要动手的，正常一行汇总。
C 级双签：配额调整、换版发布进双签（提交→复核→生效+审计痕）。查看/普通签发不进。
厂域与凭证：厂域数据服务端注入工厂号；邀测码明文只显示一次，库 sha256 不落明文、日志不落明文。
不造假面：数字为真件拉取；未达=诚实空态，成本未接=未接，不估算。

端子契约

运行时：adminDaily.runtime（admin 栈直连 harness 池聚合）

全部 admin 闸 + 舱角色写权限 + 厂域钉 + C 级双签面。
