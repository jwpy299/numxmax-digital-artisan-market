# Public Release Checklist

- [ ] secrets 与内部地址扫描零命中，人工抽查通过。
- [ ] LICENSE/NOTICE/DCO/CODEOWNERS/SECURITY/GOVERNANCE 完整。
- [ ] SBOM、依赖许可证和素材许可复核完成。
- [ ] 干净环境 npm ci、check、build、test 全绿。
- [ ] 文档不包含生产默认配置、生产完成或真实支付/训练宣称。
- [ ] DSH secrets/license/供应链复核与 Owner+C 级签字完成。
- [ ] Release 签名与 provenance 由 Owner 在仓外完成，私钥不入仓。
